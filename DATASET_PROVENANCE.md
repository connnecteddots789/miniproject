# Dataset provenance and usage

## NSL-KDD

- Canonical project information: https://www.unb.ca/cic/datasets/nsl.html
- The University of New Brunswick page currently notes that the original dataset is no longer available from that host.
- `scripts/setup_datasets.py` attempts to obtain `KDDTrain+.txt` and `KDDTest+.txt` from the public GitHub repository `defcom17/NSL_KDD`. This is a mirror, not an official hosting endpoint. The script records SHA-256 values for local download integrity but does not claim those hashes are provider-published checksums.
- Cite: Tavallaee, M., Bagheri, E., Lu, W., & Ghorbani, A. (2009). A Detailed Analysis of the KDD CUP 99 Data Set. IEEE CISDA.
- Check source repository terms and provenance before redistribution.

## UNSW-NB15

- Official provider: https://research.unsw.edu.au/projects/unsw-nb15-dataset
- Official download is linked from the provider page to a UNSW SharePoint distribution.
- Provider describes 2,540,044 records across four CSVs and also supplies a 175,341-row training split and 82,332-row testing split. It documents nine attack types plus normal traffic.
- The provider grants free use for academic research and requires citation of its papers; commercial use should be agreed with the authors. Do not redistribute the raw files without checking current terms.
- Cite at minimum: Moustafa, N., & Slay, J. (2015). UNSW-NB15: a comprehensive data set for network intrusion detection systems. MilCIS.

The user supplied a OneDrive ZIP containing the canonical paired CSV files, plus the feature dictionary CSV. The final package includes all three under `backend/data/unsw_nb15/`.

The training and testing files use the official named split. They include 43 traffic attributes plus `attack_cat` and `label`. SENTINEL uses `attack_cat` as the multiclass target when present and excludes both target columns and the `id` identifier from model inputs. The feature dictionary is retained as reference documentation and is not treated as traffic data.

The provider's dataset page is the provenance authority: https://research.unsw.edu.au/projects/unsw-nb15-dataset. The provider describes academic research use and requests citation of its associated work; commercial use requires agreement with the authors. Check the provider's current terms before redistribution. This ZIP is assembled for the user's local academic project; bundling does not grant additional rights.

The final package includes user-supplied NSL-KDD and UNSW-NB15 data files. Dataset files are not generated by SENTINEL and are not modified during packaging.


## Bundled NSL-KDD files in this project package

The user supplied an archive containing the standard NSL-KDD distribution. SENTINEL includes the canonical `KDDTrain+.txt` and `KDDTest+.txt` files from that archive. These are headerless 43-column files (41 features, attack label, difficulty). The ZIP also contained duplicate copies in a nested folder and alternate `KDDTrain+_20Percent` / `KDDTest-21` variants; those variants are intentionally not included in the active dataset directory. SHA-256 checksums are documented in `README.md`. The project setup script checks the bundled pair against the recorded SHA-256 values before attempting any network download.
